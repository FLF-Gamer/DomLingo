## 更新真实右键操作图

原生 Chrome 右键菜单不属于网页 DOM，普通 `page.screenshot()` 无法完整截取，不能用伪造的 HTML 菜单冒充。

1. 在 Chrome 中重新加载当前本地 DomLingo 构建。
2. 用仅绑定 `127.0.0.1` 的静态服务打开 [操作示例页](../demo/translation.html)。仅公开 `docs/demo/`，不要公开整个工作区。
3. 选区模式：拖选第二段完整英文，在选区内点击右键，将焦点移到“DomLingo：AI 翻译”，但不要执行。
4. 整页模式：打开相同 URL 并附加 `?mode=page`；点击空白处清除选择后，右键并高亮同一菜单项。
5. 只保存示例文章及原生菜单的裁剪区域；不要输出或保存完整浏览器窗口截图。
6. 检查图片中选区是否明显、菜单名称是否清晰，并确认没有个人信息后再引用。

- 静态操作图和结果图只使用项目编写的本地示例内容；官网演示动图只使用公开网页，不使用个人浏览内容。

- 不展示扩展设置中的 API Key，不打开账号或设备相关子菜单。
