# DomLingo v0.1.0-alpha.2

新增 PDF 选区翻译，并修复长选区分批与 PDF 侧栏连接问题。仍为 Alpha 版本，需要配置自己的模型服务。

## 本次更新

- **PDF 选中文字翻译**：在 Chrome 已打开的 PDF 中选中文字，右键选择“DomLingo：AI 翻译”，译文显示在浏览器侧栏。无需重新打开文件或填写链接，不覆盖原文。
- **PDF 矩形框选**：通过插件弹窗打开 PDF 框选阅读器，选择本地文件或 HTTPS 链接，拖动框选需要翻译的文字。支持翻页、缩放、停止、重新翻译和复制。
- **完整句子分批**：PDF 每批最多发送 4,000 个原文字符，优先按段落，超长段落只在完整句子之间切分。剩余内容继续翻译，不截断单词，不因分批增加段落空行；单句超过限制时提示缩小选区。
- **紧凑阅读界面**：缩小 PDF 译文字号和留白，工具栏与滚动正文分离。
- **侧栏断线修复**：连接断开后停止标签监听和心跳，保留已有译文，避免切换标签页、停止或重试时继续访问旧连接。

网页的整页翻译、选区原位翻译和恢复原文功能保持不变。

## 下载安装

1. 下载附件 `domlingo-chrome-unpacked-0.1.0-alpha.2.zip`，不要选择自动生成的 Source code 源码包。
2. 解压后，在 `chrome://extensions` 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 打开 DomLingo 设置，配置模型服务并测试连接。

可使用附件 `SHA256SUMS` 校验 ZIP 与 `CHANGELOG.md`。

### 更新已有安装

- 用新版解压内容替换原扩展目录，在 `chrome://extensions` 点击 DomLingo 的“重新加载”，并重新打开 PDF 侧栏、刷新需要翻译的网页。无需卸载扩展。
- 源码安装用户更新代码后运行 `pnpm install --frozen-lockfile` 与 `pnpm build`，继续加载 `.output/chrome-mv3/`。
- 本次新增 `sidePanel` 权限，用于 PDF 译文侧栏；没有新增必需的全站访问权限。配置和 API Key 存储格式不变。
- GitHub 下载版不会自动更新；旧版 Release 保留，可按需回退。

## PDF 支持范围

- Chrome 116 或更新版本；建议使用当前 Chrome 版本。
- 原生 PDF 阅读器支持可选中文字的文件。未选中文字时不会自动翻译整个 PDF。
- 独立框选阅读器支持 50 MB 以内、带文字层的 PDF。需要登录的链接可先下载文件，再从本地打开；加密文件须先解锁。
- 不支持扫描件 OCR、图片文字识别、PDF 原位改写或翻译版 PDF 导出。

## 隐私与费用

- 只把主动选中的文字发送到你配置的模型，不上传整个 PDF，也不经过 DomLingo 中转服务器。
- 原文与译文只暂存在可信浏览器会话中，不保存阅读历史；刷新、导航或关闭对应 PDF 标签页后清除。
- 切换标签页、关闭侧栏或重新选择内容会取消未完成的任务。模型服务已接收的请求可能仍产生费用。
- 模型翻译质量、速度和费用由所选服务决定；API Key 不包含在下载包中。
