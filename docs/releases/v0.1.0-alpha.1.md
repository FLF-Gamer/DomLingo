# DomLingo v0.1.0-alpha.1

这是 DomLingo 的 Alpha 开发者预览版，需要自备模型 API，并在 Chrome 开发者模式下加载。GitHub 版本不会自动更新，尚未发布到 Chrome Web Store。

## 本次更新

- **选区翻译**：选中一句话、一段或多段英文，右键选择“DomLingo：AI 翻译”，只翻译选中的文字；未选中时则翻译整页正文。
- **段落更快显示**：哪个完整段落先翻译好，就先显示，不必等待前面的慢批次；同一段不会只替换一半。
- **整页/选区切换修复**：局部翻译后点击空白处，再次右键即可翻译全文。扩展会先取消局部任务并恢复原文，迟到响应不会覆盖新任务。
- **图文使用指南**：README 补充模型配置、两种模式的真实右键操作及翻译效果示例。
- **插件图标**：工具栏、扩展管理页、弹窗和扩展页面使用统一的 DomLingo 图标。
- **HTTP 页面兼容**：会话 ID 不再依赖仅安全上下文可用的 `randomUUID`。

## 下载安装

1. 下载本页附件 `domlingo-chrome-unpacked-0.1.0-alpha.1.zip`，不要下载自动生成的 Source code 源码压缩包。
2. 可使用随附 `SHA256SUMS` 校验 ZIP 与 `CHANGELOG.md`。
3. 解压 ZIP，打开 `chrome://extensions` 并开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。
5. 点击 DomLingo 图标，打开设置，配置自己的模型服务并“测试连接并保存”。

### 更新已有安装

- 下载并解压新版到原来加载的扩展目录，再在 `chrome://extensions` 点击 DomLingo 的“重新加载”，然后刷新正在阅读的网页；无需先卸载扩展。
- 从源码安装的用户更新代码后运行 `pnpm install --frozen-lockfile` 和 `pnpm build`，继续使用 `.output/chrome-mv3/`，不必另外解压 Release ZIP。
- 普通配置和设备加密的 API Key 存储格式未变；本次没有新增配置迁移。
- 如需回退，可从旧版 Release 下载旧包，替换原扩展目录后重新加载。请勿把 API Key 写入公开 Issue。

## 两种翻译模式

- **整页翻译**：先取消文字选择，再右键选择“DomLingo：AI 翻译”；也可以使用弹窗里的“翻译当前页面”。这里只处理识别出的正文，不翻译页面全部界面文字。
- **选区翻译**：先选中需要阅读的英文，再在选区上右键选择同一个菜单项。译文原位替换，选区外内容保持不变。

两种模式都支持停止、失败重试和恢复原文。选区可以连续翻译；恢复时按相反顺序撤销，失败重试只针对最新一次选区。

## 隐私、权限与费用

- 没有新增安装权限、必需网站访问权限或请求中转服务。
- 只有用户主动翻译后，正文才会直接发送到所选模型端点；选区模式只发送选区内可翻译文字和上下文。
- API Key 继续由本机设备密钥加密保存，不进入网页脚本、发布 ZIP、日志或示例配图。
- 模型调用费用和数据处理规则由用户选择的服务商决定；取消客户端任务不保证撤销已到达服务商的请求或费用。

## 已知限制与验证范围

- 仍为 Alpha：主要适合普通 HTTP/HTTPS 英文文章与文档站，不是稳定版或商店自动更新版本。
- 选区仅支持主页面；代码、隐藏内容和编辑器会跳过，不支持 iframe 内的选区。
- 不支持 Chrome 内部页、Chrome Web Store、原生 PDF、图片/OCR、Canvas 或 closed Shadow DOM 的完整翻译。
- 动态新增正文和 SPA 新路由不会自动翻译，需要重新发起任务。
- 模型可能返回截断或不符合格式的结果，可使用“重试失败内容”；质量、速度和费用取决于所选服务。
- 已通过选区范围、连续恢复、模式切换、取消/迟到响应、图标与构建的自动化回归；原生右键菜单和选区高亮已在真实 Chrome 中检查。
- 本次验证使用本地示例和固定模型响应，没有调用真实模型；真实服务的端到端体验仍需早期用户试用反馈。

完整变更见随 Release 提供的 `CHANGELOG.md`。旧版 `v0.1.0-alpha.0` 保留，不覆盖原有下载包。
